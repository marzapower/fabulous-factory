# Plan — i18n via `@factory/i18n` (`[locale]` as-needed routing)

**Status:** APPROVED WITH CORRECTIONS (critique panel 2026-08-27, corrections M1–M20 folded in) · **Branch:** `feat/i18n` (off `develop`) · **Release:** 0.4.0

Product decisions were settled in the design interview (see ADR-0007, written as part
of this work). This document is the engineering plan: contracts, files, tests, exclusions.

## 0. Decisions carried in (not re-litigated here)

| #   | Decision                                                                                                                                                                                                                                                                                                   |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | `@factory/i18n` (`packages/i18n`) is a **base package** shipped to every preset, a DAG **leaf** (imports no other `packages/*`), wrapping `next-intl` — the only place `next-intl` may be imported, with a single unavoidable seam: `apps/*/next.config.ts`'s `next-intl/plugin` import (build-time only). |
| D2  | Every page of every preset moves under `app/[locale]/`; `app/api/**` stays at root. `localePrefix: "as-needed"`: `/` = default locale, `/en/x` → redirect to `/x` (status as observed from next-intl, see V-6), `/it/x` = Italian, unknown prefix → 404.                                                   |
| D3  | No `Accept-Language` detection. `NEXT_LOCALE` cookie is written **only** by the switcher; when present and valid and ≠ default, the proxy redirects an unprefixed page URL to the prefixed one.                                                                                                            |
| D4  | Locales are declared in code, per app (`apps/<app>/i18n/config.ts`). No env var. A single-locale app is the degraded state — there is no off switch.                                                                                                                                                       |
| D5  | JSON catalogs per package (`<pkg>/messages/<locale>.json`), namespace = package name (`ui`, `app`), keys `ns.component.key`. Merged **by the app** (DAG: the leaf cannot import `packages/ui`). Per-key fallback to the default locale. Typed keys.                                                        |
| D6  | `packages/ui` ships `en` + `it`; `apps/nothing` ships `en` + `it`; `apps/untangle` / `apps/brainstorm` declare `["en"]` and keep their product-specific copy hardcoded (translatable mechanism present, not exercised).                                                                                    |
| D7  | `createAuthProxy({ i18n })` composes locale routing **before** the allowlist, inside `packages/ui/src/middleware.ts` (guarded zone → fab-bastion).                                                                                                                                                         |
| D8  | `app/[locale]/layout.tsx` becomes the root layout. `alternateLinks: true` (hreflang via `Link` header) + `<html lang>`. `<LocaleSwitcher />` in `packages/ui`, hidden with one locale.                                                                                                                     |
| D9  | Emails, `defineHandler` error messages, LLM output: **out of scope**, English only, recorded in the ADR.                                                                                                                                                                                                   |
| D10 | Process: this plan → fresh-context critique → parallel implementation (disjoint files) → fab-warden + fab-bastion → `pnpm check` + `pnpm compose` + scaffold-and-check.                                                                                                                                    |

## 1. Real state (from the Phase 1 analysis)

- Packages are consumed as **source** via `package.json#exports` → `./src/*.ts`; no build step. Server-only packages start `src/index.ts` with `import "server-only"`; client code needs its own subpath (precedent: `@factory/config/client`).
- DAG is **deny-by-default** (`.dependency-cruiser.cjs`): every package has a `dag-<pkg>-imports-…` rule with a closed `pathNot` allowlist. `packages/ui` may import only `config|auth|ui` (line ~271). Vendor confinement rules use `to.path: "(^|/)node_modules/<vendor>(/|$)"`; the better-auth rule carves out three files via `from.pathNot`.

#### Contracts

```ts
// src/index.ts  (isomorphic, imports only next-intl/routing types + ./routing)
export type Locale = string;
export interface Catalog<NS extends string = string> {
  namespace: NS;
  /** locale → nested message tree (JSON). Must contain the app's defaultLocale. */
  messages: Record<Locale, Messages>;
}
export type Messages = { [key: string]: string | Messages };

export interface I18nConfigInput<L extends readonly [Locale, ...Locale[]]> {
  locales: L;
  defaultLocale: L[number];
  catalogs: readonly Catalog[];
  /** Cookie name, default "NEXT_LOCALE". Read by the proxy + written by the switcher. */
  cookieName?: string;
}

export interface I18nConfig<
  L extends readonly [Locale, ...Locale[]] = readonly [Locale, ...Locale[]],
> {
  locales: L;
  defaultLocale: L[number];
  cookieName: string;
  routing: LocaleRouting; // see ./routing — serialisable, passed to createAuthProxy and I18nProvider
  /** Merged, namespaced messages for `locale`, with per-key fallback to defaultLocale.
   *  Throws RangeError for an unknown locale. */
  messagesFor(locale: Locale): Messages;
}

export function defineI18n<L extends readonly [Locale, ...Locale[]]>(
  input: I18nConfigInput<L>,
): I18nConfig<L>;
//   - throws if defaultLocale ∉ locales, if locales has duplicates, or if a catalog lacks defaultLocale messages
//   - messagesFor(l) = for each catalog: { [ns]: deepMerge(messages[default], messages[l] ?? {}) }
//   - registers the config in a module-level slot so `@factory/i18n/server` helpers can read
//     defaultLocale/cookieName without the app threading it (server side; the app's request.ts
//     imports the config, so the slot is always populated before any server helper runs).
export function getI18nConfig(): I18nConfig; // throws if defineI18n has not run (server misuse guard)

// Message-registry interface — packages augment it, the app reads it (see §2.4).
// M8: an index signature, not `{}` — `@typescript-eslint/no-empty-object-type` is an error under
// tseslint recommended, and the signature also satisfies next-intl's AppConfig["Messages"] constraint.
export interface MessageRegistry {
  [namespace: string]: unknown;
}
declare module "next-intl" {
  interface AppConfig {
    Messages: MessageRegistry;
  }
}

// next-intl root re-exports (M1/M2) — the ONLY sanctioned import path for these in every package and app:
export {
  useTranslations,
  useLocale,
  useFormatter,
  useMessages,
  useNow,
  useTimeZone,
  NextIntlClientProvider,
  hasLocale,
} from "next-intl";
```

```ts
// src/routing.ts  (pure; NO next-intl import; importable from the proxy and client)
export interface LocaleRouting {
  locales: readonly Locale[];
  defaultLocale: Locale;
  cookieName: string;
}
/** "/it/login" → { locale: "it", pathname: "/login" }; "/login" → { locale: defaultLocale, pathname: "/login", prefixed: false };
 *  "/it" → { locale: "it", pathname: "/" }; "/itx/login" → default locale, pathname unchanged (strict segment match). */
export function stripLocale(
  routing: LocaleRouting,
  pathname: string,
): { locale: Locale; pathname: string; prefixed: boolean };
/** localizeHref(r, "it", "/login") → "/it/login"; default locale → "/login"; external/hash/query-only hrefs untouched;
 *  already-prefixed hrefs are re-prefixed (strip first).
 *  M5: localizeHref(r, "it", "/") === "/it" and localizeHref(r, "en", "/") === "/" (pinned, tested).
 *  M4: MUST NOT be handed a raw request pathname — its `external → untouched` branch is an open-redirect
 *  gadget for "//evil.com/x" / "/\evil.com"; the proxy validates the path shape BEFORE calling it. */
export function localizeHref(routing: LocaleRouting, locale: Locale, href: string): string;
export function isLocale(routing: LocaleRouting, candidate: unknown): candidate is Locale;
```

### 2.2 Proxy composition — `packages/ui/src/middleware.ts` (guarded zone)

```ts
export function createAuthProxy(opts: {
  i18n: LocaleRoutingHandler; // REQUIRED — every preset passes it (D4: always on)
  extraExactAllowlist?: readonly string[];
}): (req: NextRequest) => Response; // never undefined any more
```

Algorithm (ordered; each step cites the intent):

1. `pathname = request.nextUrl.pathname`. If `pathname === "/api" || pathname.startsWith("/api/")` → **API branch**: exactly today's logic on the raw pathname (`isPublicPath` → `NextResponse.next()`; cookie → `next()`; else redirect to `/login`). No locale handling — `/api/health` stays byte-identical for scaffold-and-check.
2. **Page branch**: `const intl = i18n.handle(request)`. If `!intl.ok` (a redirect: `/en/x → /x`, trailing-slash normalisation, …) → return `intl` unchanged. (Safe: the redirected request is proxied again.)
3. `{ locale, pathname: bare, prefixed } = stripLocale(i18n, pathname)`. Cookie redirect (D3), guarded (M4/M5):
   - `cookieLocale = request.cookies.get(i18n.cookieName)?.value`; proceed only if `isLocale(i18n, cookieLocale) && cookieLocale !== i18n.defaultLocale && !prefixed`;
   - **path-shape guard (M4):** proceed only if `bare.startsWith("/") && bare[1] !== "/" && bare[1] !== "\\"` — otherwise fall through to step 3b;
   - `target = localizeHref(i18n, cookieLocale, bare) + request.nextUrl.search`; **loop guard (M5):** proceed only if `target !== pathname + request.nextUrl.search`;
   - `url = new URL(target, request.url)`; **origin assertion (M4):** proceed only if `url.origin === request.nextUrl.origin`;
   - `return NextResponse.redirect(url)`.
     (`/en/x` was already redirected to `/x` by step 2 on the previous hop, so this also covers it.)
     3b. **API entries are unreachable from the page branch (M14):** `if (bare === "/api" || bare.startsWith("/api/"))` → skip step 4 and go straight to step 5 (`/it/api/health` is never public; `extraExactAllowlist` is server-to-server only).
4. `if (isPublicPath(bare, extraExact)) return intl;`
5. `if (getSessionCookie(request)) return intl;`
6. `return NextResponse.redirect(new URL(localizeHref(i18n, locale, "/login"), request.url));` — default locale → `/login` (existing tests stay valid), `it` → `/it/login`.

`isPublicPath` is unchanged (still exported, still matched on locale-less paths). The matcher string in each `proxy.ts` is unchanged.

Security notes for the bastion review: the locale strip is a strict segment match against the declared list (`/itx/…` is not stripped); the `x-middleware-rewrite` header from next-intl is forwarded untouched only via `intl` itself; the `NEXT_LOCALE` cookie is **untrusted input whose only sanctioned effect is selecting a member of the declared `locales` array — never a source of any part of a URL path** (M15); step 3 validates the path shape (single leading `/`, no `\`) _and_ asserts `url.origin === request.nextUrl.origin` before redirecting (M4); the query string is preserved, the hash never exists server-side; the API allowlist entries cannot be reached through a locale prefix (M14).
