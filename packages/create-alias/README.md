# create-fabulous-factory

Alias package so `npm create fabulous-factory` / `pnpm create fabulous-factory` work — it forwards straight to [`fabulous-factory`](https://www.npmjs.com/package/fabulous-factory), the actual installer CLI.

## Usage

```bash
pnpm create fabulous-factory
# or
npm create fabulous-factory@latest
```

See the [`fabulous-factory`](https://www.npmjs.com/package/fabulous-factory) package and the [main repository](https://github.com/marzapower/fabulous-factory) for full documentation.
